Daten & Sicherung

Das Tresor-Passwort ist in der App fest verdrahtet — beim Entsperren wird nur noch gegen diesen Wert geprüft (kein GitHub-Abgleich). Schichten liegen lokal verschlüsselt unter wdr-v5-vault — ohne gespeichertes Klartext-Passwort im Browser.

Hinweis: Schutz gilt für diese Installation. Wer Zugriff auf Gerät und Passwort hat, kann entsperren. Bei file:// kann Verschlüsselung ausfallen — Seite per lokalem Server oder HTTPS öffnen.

Backup (.json): unverschlüsselte Kopie zum Archivieren; sicher aufbewahren. Import:

GitHub

Laden ohne Token: Jeder mit dem Tresor-Passwort kann Schichten per Knopf oder Auto-Sync holen, wenn das Repo öffentlich ist (GitHub liefert die Datei anonym). Hochladen geht nur mit optionalem GITHUB_REMOTE.token im Skript. Daten sind Klartext im Repo — sensible Repos nicht öffentlich machen, wenn das stört.
